        macOS

        If macOS says the app can't be opened, right-click Your Bot in Applications and choose Open, or run:

        xattr -dr com.apple.quarantine "/Applications/Your Bot.app"

        Windows

        If SmartScreen appears, choose More info → Run anyway. PCs with Smart App Control turned on block unsigned apps with no override.

        Linux

        The strict sandbox profile needs Python 3 with venv, bubblewrap and gcc. The install script adds them for you. The AppImage needs FUSE 2.
